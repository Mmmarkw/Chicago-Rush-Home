# Chicago Rush Home 🏙️🚗

A browser-based arcade driving game inspired by Chicago rush-hour traffic.

Play directly in your browser through GitHub Pages.

## Features

- Canvas-based arcade driving gameplay
- Dynamic traffic and collision mechanics
- Boost and energy-management system
- Route progression through Chicago landmarks
- English and Chinese interface
- Responsive UI for different screen sizes

## Built With

- HTML5
- CSS
- JavaScript
- Canvas API

## Motivation

Built as a small personal project to experiment with interactive web development,
game mechanics, and browser-based visualization.
